# omahop reference pack

132 plain SVG icons (CC0) for common Linux desktop apps and the apps of one Omarchy machine. Test fixture for the omahop icon picker and builder.
Made by `tools/refpack/gen.sh` from `tools/refpack/apps.tsv`; do not edit the SVGs by hand, regenerate.

Install: `ln -s "$PWD" ~/.config/omahop/packs/omahop-reference` (run inside this folder), then pick it in the settings window.
Details: `docs/icon-packs.md`, section Reference pack.
