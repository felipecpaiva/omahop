# v2-tilehop-citrus: Citrus (golden yellow)

The same shapes as `v2-tilehop` with a new palette, made by `tools/recolor.py`. Nothing but colour changed.

| Role | Hex |
|---|---|
| Ground (icon tile, and ink on light) | `#1a1812` |
| Main shape | `#fff5d6` |
| Accent: the tile that is hopped to | `#ffc83d` |
| Motion ticks | `#7c7560` |
| Accent on light backgrounds | `#9a6b00` |
| Ticks on light backgrounds | `#6a634f` |

|---|---|---|---|

| accent on ground | 11.5:1 | 3.0:1 | graphics, ok |
| ticks on ground | 3.9:1 | 3.0:1 | decoration only, ok |
| ink on paper | 16.0:1 | 7.0:1 | AAA, ok |
| deep accent on paper | 4.2:1 | 3.0:1 | graphics, ok |
| light ticks on paper | 5.4:1 | 3.0:1 | decoration only, ok |
