# omahop v1.0.0-rc.4: tests for any number of monitors

No change to the plugin itself. The monitor tests now cover as many monitors as are attached, and a model covers the rest.

- `lua/test_monitors.lua`: models 1 to 6 monitors with no hardware. Every monitor is the focus in turn, under every window-set setting, and the answer is compared with an independent brute-force check. Monitors are also "unplugged" two ways (windows move to another monitor, or keep the name of a gone one). 193 checks. A deliberately broken filter fails 98 of them.
- `tests/live_monitors.py`: runs on the real monitors you have attached. Each extra monitor gets two test windows. From each monitor in turn, the "active" list equals what Hyprland says is on that monitor, the "all" list holds every test window, and picking a window on any other monitor focuses it and moves focus there. Passed with two monitors; it skips itself with one.

Still open before `v1.0.0`: a real unplug of a monitor with windows on it, and a look at the peek strip on each screen. See `docs/validation-checklist.md`.
