# omahop v1.0.0-rc.2: every app icon shows

Fixes the missing app icons: the list and cards showed a broken-image square instead of the app's icon (Google Chrome and every other app).

Why it happened: Omarchy gives its app-icon library only to menu plugins, and omahop is not one. Omahop now builds its own icon index from the standard icon folders (`tools/icon-index.sh`) and picks icons with one small, tested module (`IconResolve.js`).

What is covered: the icon named in the desktop entry, an absolute icon path, window classes in another letter case, classes with spaces or reverse-DNS names, icons outside the app folders, and a neutral generic icon for an app that has none. A test checks all 207 app ids installed on the test machine.

Also: the cards test no longer assumes a dark theme.

Still a release candidate: the second-monitor checks in `docs/validation-checklist.md` are open.
