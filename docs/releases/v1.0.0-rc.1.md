# omahop v1.0.0-rc.1: release candidate

All planned features are in: list and cards styles, thumbnails, type to search, settings window, mouse and quick actions, optional peek strip, same-app shortcut, app rules, quick jump keys.

New in this candidate:

- README "Requirements and what it touches": what omahop reads, writes and which keys it takes.
- Launch material in `docs/launch/` (marketplace draft, repo settings, media list).

Why a candidate and not 1.0.0: the second monitor and unplug paths are tested in code but not on real hardware. After the hand checks in `docs/validation-checklist.md` pass, the same code becomes `v1.0.0`.

Install and the full picture: see the README. All earlier highlights: `docs/releases/`.
