# omahop v1.0.0

The first full release. Alt+Tab for Omarchy floating workspaces: a list or cards with window pictures, type to search, mouse and quick actions, an optional peek strip, a same-app shortcut, app rules, quick jump keys, and a settings window that follows the Omarchy theme. By default it acts only on floating workspaces. Tiling workspaces keep Omarchy's own Alt+Tab.

Since the last candidate: nothing in the plugin changed. The two checks that were open were done by hand on two monitors and worked: unplugging a monitor with windows on it, and the peek strip on each screen.

What was tested: unit and glue tests, live tests with a virtual keyboard and mouse for every feature, icons for all 207 installed apps, and monitors: a model of 1 to 6 monitors plus a live run from every attached monitor.

Install: see the README. What it reads and writes: see "Requirements and what it touches" in the README.

Next ideas (not promised): keep the list open while you search, and icon packs. See `docs/ROADMAP.md`.
