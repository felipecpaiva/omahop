# omahop v1.0.0-rc.3: two monitors tested

A second monitor was connected for this round, and the whole automated suite passes with it.

New: `tests/live_monitors.py` checks the monitor setting live: with `windows.monitors = "active"` the other monitor's window is not listed, with `"all"` it is; search finds it; picking it focuses it and moves focus to that monitor; the list from there still holds every window. With one monitor the test skips itself.

Docs updated to match: README (status, how to run the tests), validation checklist, launch notes, plan, batch log.

Still open before `v1.0.0`: unplugging a monitor while windows are on it (the capture crash from the research), and a peek strip on each screen by hand. See `docs/validation-checklist.md`.
