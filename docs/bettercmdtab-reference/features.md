# BetterCmdTab feature reference (B1..B65)

## 1. What it is

BetterCmdTab (https://github.com/rokartur/BetterCmdTab, site bettercmdtab.app) is a free, open-source Cmd+Tab replacement for macOS 13+, native Swift/AppKit (+ SwiftUI settings, private CGS/SkyLight calls isolated in `System/PrivateAPIs.swift`). Menu-bar accessory app. Created 2026-05-22, last push 2026-11-03, 856 stars, 35 releases (current 26.8-beta.10, Homebrew cask `bettercmdtab` and `@beta`). Open issues (9): top/bottom half tiling, key repeat for arrow/vim nav, Affinity tab support, list follows previous monitor not cursor monitor, phantom helper app entries, letter hints regression, TextEdit/Preview ignore current-Space filter, activation failure on macOS 26.6.1. No telemetry; only network use is the GitHub update check. Inspired by AltTab, Witch, Contexts (stated in README).

**License: GPL-3.0.** Do NOT copy code into an MIT project. Ideas and behaviors only; write clean-room. (Uses a separate `BetterShortcuts` package, license UNVERIFIED.)

Method: read README, ARCHITECTURE.md, web docs (`web/content/docs/en/*.mdx`), `App/ConfigSchemaDocs.swift` (every key, description, range), `Preferences.swift` init block (defaults), enum sources, selected Input/Windows/Switcher files, release notes 26.8-beta.10. Not read line by line: SwitcherController.swift (6.5k lines), HotkeyTap, Activator, SwipeTrigger internals, visual layout code; anything depending on those is marked UNVERIFIED.

Source abbreviations: README = README.md; CSD = `BetterCmdTab/App/ConfigSchemaDocs.swift`; PREF = `BetterCmdTab/App/Preferences.swift`; DOC-x = `web/content/docs/en/x.mdx`; ARCH = ARCHITECTURE.md; REL = GitHub release 26.8-beta.10 notes.
Portability: easy / medium / hard / impossible for Hyprland + Quickshell (QML layer-shell UI, hyprctl/IPC for windows, `hyprland-global-shortcuts`/binds for keys).

## 3. UX ideas NEW compared with DockDoor and Contexts

1. **Tap vs hold with a reveal delay (B1).** Quick tap switches with no panel at all; panel only shows after `revealDelayMs` (100 ms). Removes flicker for fast MRU toggling. DockDoor has hold/instant (D38) but BetterCmdTab couples it to a tunable delay and documents "raise it if the panel flashes".
2. **Window shelf and Down-arrow drill (B15, B16).** App-level row with a second strip of that app's windows; Down opens it only where Down would otherwise be redundant (single-row grid). Keeps app switching one level and window picking a deliberate second step.
3. **Pure-function selection math (PrimedSelection).** The first-press landing index is a pure function (`count, delta, anchor, startsInMiddle, excludedAt`), which makes edge cases testable (frontmost pinned, excluded, 1 item). Good design pattern for omahop even though code is GPL.
4. **Persistent, user-assigned letter mappings and home-row single letters (B26 to B30).** App-to-letter map, one-hand mode (letters from the side of the held modifier), home-row-first one-letter-per-window, hint exclusions to free letters. Contexts has learned search shortcuts (C13) but not stable mappings or one-hand rule.
5. **Scoped shortcuts + per-shortcut overrides (B36 to B38).** Each hotkey can have its own layout, scale, sort, space scope. "Exclude current app" per shortcut so the first press always leaves.
6. **Per-app `ignore: whenFullscreen` (B40).** Pass the chord through to games and remote desktops only while fullscreen; warning text about the lock-out of `always`.
7. **Per-app title exclusion fragments (B41).** Hide only certain windows of an app (e.g. Private Browsing) without hiding the app.
8. **Status-glyph grammar (B43).** Seven small glyphs, including "not running, Return launches" and "recently closed, Return reopens", merging a launcher into the switcher.
9. **Recently closed apps in search (B32).** Reopen list capped by `recentlyClosedLimit`.
10. **`clickOnMouseUp` menu-style click (B50).** Press, drag onto another row, release to pick; release off rows cancels. Not in either reference.
11. **Opt-in config file by existence (B60).** File never auto-created, creation = switch; two-way live sync, atomic-save aware watcher, debounces (200/500 ms), flush on quit, full-snapshot rewrite warning, clamp-not-reject, enum fallback, generated JSON Schema with enum descriptions and ranges. Far more complete than DockDoor's JSON export (D89).
12. **Initial selection `middle` (B9).** For stable sorts (alphabetical, launch order) a first press landing mid-list.
13. **Dock-order sort and launch-order sort (B8).** Stable, non-reshuffling orders as alternative to MRU.
14. **Instant Space switch (B11) and pointer warp to target display (B6).**
15. **Fade-in/out and animation toggles honoring Reduce Motion (B58).**
16. **Survivor trigger architecture (B22).** Separate fallback path when the main key hook is deaf; analogous resilience idea: omahop should keep a plain Hyprland `bind` as fallback if a Quickshell grab fails.
17. **Thumbnail request gate (B59).** Generation tokens so late captures cannot repopulate a cleared cache; 10 Hz one-shot recaptures rather than persistent streams to avoid the system capture indicator.
18. **Hold-modifier release polling (B22).** A cheap state poll (33 Hz while held, 4 Hz when parked) is the fallback when release events are not delivered.

## 4. Top 6 to port to omahop (ranked)

1. **Tap vs hold with `revealDelayMs` (B1).** Biggest felt-quality win for Alt+Tab; one timer in Quickshell, gated by `bindr` release. Medium effort, high value. Idea only; no code needed.
2. **Opt-in config file with live reload, clamp-not-reject, enum fallback, partial import (B60).** Fits Omarchy dotfile culture; Quickshell FileView + JSON, never auto-create; ship a JSON Schema so editors complete keys. Easy.
3. **Per-shortcut profiles: scoped shortcuts and overrides, including "exclude current app" (B36 to B38).** Gives omahop several binds (all windows, current workspace, current class) with different layout/sort. Easy; define a profile table once and reuse.
4. **Space/workspace scope `visibleSpaces` plus sort `mruWindows` / stable sorts with `initialSelection: middle` (B8, B9, B10).** Maps to Hyprland workspaces on multiple monitors; floating-workspace case benefits from "visible on any monitor" scope. Easy.
5. **Letter hints with persistent app-to-letter map, one-hand and home-row modes (B26 to B30).** Keyboard-first, fits tiling-WM users. Easy, no OS dependency.
6. **Per-app rules: hide, `ignore whenFullscreen`, title-fragment exclusions, groupWindows (B17, B40, B41).** Also covers games/VMs. Easy via window class/title and `fullscreen` state.

Runners-up: hover action bar (B46), status-glyph grammar (B43, audio via PipeWire), clickOnMouseUp (B50), fuzzy subsequence search with folded rows (B31), window shelf (B15).
