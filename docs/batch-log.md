## v1.3 part B (2026-11-07, branch v1.3-action-keys): quit and minimize by key

New setting `action_keys` (text, group Shortcuts, default empty = off): `key=action` pairs such as `q=close, m=minimize`. Pure `lua/action_keys.lua` (`parse`, `drop_conflicts`, `resolve`; keys are one letter or digit so navigation keys can never clash; an unknown action, a bad key or a key that a hint uses is reported and skipped, the hint wins).
