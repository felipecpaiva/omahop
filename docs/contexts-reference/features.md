Exact setting names are therefore only those quoted in W. Macworld (2014, v1.4) could not be fetched. Current: v3.9 (2022-08-27), macOS Ventura to Sequoia, $9.99, free trial. Last release 2022; maintained status UNVERIFIED.

## 1. What it is

Contexts is a paid macOS window switcher whose core idea is "windows, not apps, as the unit, in a plain vertical list, reached with two or three keystrokes". Instead of the horizontal app-icon strip of Cmd+Tab, it shows a vertical list (icon, app name, window title per row) of every window, ordered by last use, grouped/sortable by Space. It offers four ways in: a Cmd+Tab replacement list, a type-to-search window (Ctrl+Space), "Fast Search" (hold a modifier plus 1-2 letters, release to jump, no panel needed), and a persistent auto-hiding Sidebar ("basically a Dock for your windows"), plus a trackpad scroll gesture. Tagline: "Radically simpler & faster window switcher for Mac." (H)

## 3. UX principles (each verified from sources)

1. One Tab goes to the PREVIOUS window (second item preselected), so Tab+release toggles between two windows. (W 3.7.1) Verified.
2. List is ordered by last activation, only the activated window moves up; not by Desktop position nor grouping all windows of an app. (W 3.7.1, 3.1) Verified.
3. Windows, not apps, are the unit; titles shown so same-app windows are distinguishable. (H) Verified.
4. Hold-modifier then release commits; Esc cancels without switching. (H, W 0.9.24, 2.9) Verified.
5. Delay before the list appears (like macOS), so quick Tab-release flips instantly with no flash; delay can be turned off. (W 2.8.1, 2.9) Verified.
6. Never require looking: search learns your choices; Fast Search needs 1-2 chars and no panel. (H, M) Verified.
7. Less-used windows sink (minimized to bottom, always-on-top sink, hidden optional). (W) Verified.
8. Panel stays open after close/quit so you can triage many windows. (W 2.2.0) Verified.
9. Hover does not hijack keyboard selection by default after complaints (1.4), later made a toggle. (W) Verified.
10. Everything configurable per switcher, so the simple default stays simple. (W 3.3.1) Verified.
11. "Hundreds of switches a day" framing: optimize the common path, not the rare one. (H) Marketing claim.

## 4. macOS baseline (what Contexts improves on)

All from general macOS knowledge, NOT fetched this session (UNVERIFIED against Apple docs).
- Cmd+Tab: horizontal strip of APPS (one icon per app, no titles), ordered by recent use, first Tab selects previous app. Hold Cmd, Tab/Shift+Tab move, release commits; Q quits and H hides the highlighted app, 1 shows app windows (Sonoma+ varies), arrow keys and mouse work. Windowless apps listed; minimized windows are not selectable (hold Option on release to restore them).
- Cmd+` (backtick): cycles windows of the frontmost app only, no list (immediate), Shift reverses; respects Spaces only if "Displays have separate Spaces"/current space rules (window-on-other-Space quirks).
- Mission Control (F3 / Ctrl+Up): bird's-eye thumbnails of all windows grouped by Space/app, spaces bar on top; mouse-centric, slow animation, no search.
- App Exposé (Ctrl+Down): thumbnails of only the frontmost app's windows; Misses titles; trackpad 3 or 4 finger swipe down.
Gaps Contexts fills: no window titles, app-level switching, no search, no Space filter, no quick close/minimize in the list, animation delay.

## 5. Worth porting first (ranked)

1. C3+C4+C5 Alt+Tab with press/release semantics: list on hold, first Tab = previous window, MRU order, release commits, Esc cancels. Core of the value.
2. C1+C2 Vertical list with icon, app name, window title, one row per window (Quickshell overlay, per monitor C22).
3. C28 Responsiveness: delay-before-show (~100-150 ms) so quick Alt+Tab flips with no flash (C3), and a preloaded window.
4. C16 Keyboard navigation: Tab/Shift+Tab, arrows, K/J, Esc, Enter; plus mouse click and hover (C21).
5. C17 Quick actions in list: close window, quit app (SIGTERM), move to scratch/special workspace as "minimize"; keep list open after action.
6. C11+C13 Type-to-search with non-consecutive/acronym fuzzy match and learned query-to-window shortcut.
7. C9+C10+C8 Workspace filter (all / current workspace) and grouping/sorting (special-workspace windows to bottom); second switcher mode for same-app windows (C6, Alt+`).
8. C23 Ignore rules by class and title regex (config JSON); then C26 Omarchy-theme following.
Defer: C14 Fast Search (needs lone-modifier handling), C18 Sidebar, C20 gesture, C24, C25, C15.
